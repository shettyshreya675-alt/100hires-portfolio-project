## Why This Topic

100Hires works in B2B recruiting, meaning cold outreach is not just a tactic - it is how the business grows. I wanted to understand how top practitioners build pipeline in practice, not just what guides say.

---

## How I Collected This Data

- YouTube transcripts - fetched programmatically using the Supadata API via a custom Python script (fetch_transcripts.py)
- LinkedIn posts - manually collected from each expert profile
